Dynamic DOM + refresh()

The DOM stays your responsibility — there is no addTab()/removeTab() and no MutationObserver. After your code changes the panels markup, call refresh() and the instance re-reads the DOM: new listeners, re-synced ARIA and ids, the active tab kept if its panel still exists.

One

Add a few panels, then arrow all the way to the right — the new tabs are fully wired.

Two

Remove the last panel while an earlier tab is active and the selection is preserved.

Calling refresh() repeatedly is safe — listeners are never bound twice, so events don't start firing multiple times.

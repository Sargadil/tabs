Vertical orientation

Vertical tabs need two independent things:

  1. options.orientation: 'vertical' — switches the keyboard model to ArrowUp/ArrowDown and sets aria-orientation="vertical".
  2. the tabs--vertical class on the container — pure layout, from the bundled CSS.

Account

ArrowUp / ArrowDown move between tabs.

Notifications

Home / End jump to the first / last tab.

Security

Left/Right arrows do nothing in vertical mode.

Drop either piece and it breaks in a different way: no option → wrong arrow keys; no class → correct keys but the nav still sits above the panels.

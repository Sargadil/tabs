Custom navigation markup

When the nav already exists in the DOM (your own classes, your own order), set options.useCustomNav: true and point the three classes.tabsNav* selectors at it. The library wires ARIA and keyboard behaviour onto the existing elements instead of generating a nav from the panel titles.

Docs

The button text is whatever you put in the markup.

Support

There must be one nav element per panel.

Settings

Plain <button> elements get type="button" added automatically.

A custom nav / panel count mismatch is rejected at construction with a [@sargadil/tabs] … error.

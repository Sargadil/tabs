Manual activation

With activationMode: 'manual' the arrow keys and Home/End only move focus. The focused tab is selected only on Enter, Space, or a click.

focused: – selected: 0

Report A

Tab into the list, press an arrow key, and watch "focused" change while "selected" stays put.

Report B

Press Enter or Space to actually activate the focused tab.

Report C

Useful when selecting a tab is expensive — see the events example for lazy loading.

In the default 'automatic' mode, "focused" and "selected" would always match.

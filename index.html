Vertical orientation

orientation: 'vertical' switches the keyboard model to ArrowUp/ArrowDown and sets aria-orientation="vertical". Add the tabs--vertical class for the matching sidebar-style layout (nav beside the panel instead of above it).

Manual activation mode

activationMode: 'manual' — arrow keys move focus without selecting; the tab only activates on click, Enter, or Space. Try tabbing in, then arrowing between tabs: notice the panel doesn't change until you press Enter/Space. Pairs well with the tabs:change event for lazy-loading expensive panel content.

Custom navigation markup

useCustomNav: true — bring your own nav markup (your own classes, your own extra wrapper elements) instead of letting the library generate the tablist. Useful when the nav needs icons, badges, or a layout the default generator doesn't support.

Custom nav titles

Override the auto-generated nav button text with options.customNavTitles — the panel's own .tab-panel__title stays untouched, only what shows up in the tablist changes. (The data-nav-title markup attribute does the same thing per-panel — see the README.)

Responsive nav in a narrow container

The nav never wraps — it scrolls horizontally the moment it doesn't fit, reacting to whatever actually constrains its width. This instance is the same as "Default" above, just placed inside a 320px-wide box, on a full-width desktop screen, to prove it's the container width that matters, not the viewport.
